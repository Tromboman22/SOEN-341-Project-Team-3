	  filterable application history. Job seekers see friendly status names (submitted = Pending,
	  shortlisted = Interview, etc.). Links added on the applicant dashboard. No new npm packages.
	- 20 unit tests in tests/analytics.test.js using node:test, in the same style as the existing tests.
